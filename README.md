# ⏰ Cron Job & Shell Scripting

A hands-on Linux project for learning and practicing **Cron Jobs, Shell Scripting, automated logging, and error monitoring**.

## 📌 Project Overview

This repository contains practical examples of using Linux `cron` to automate recurring tasks and shell scripts to monitor and log system activity.

The project focuses on understanding how scheduled jobs work in Linux and how their output and errors can be tracked through log files.

## 🛠️ Topics Covered

* Linux Cron Jobs
* Crontab
* Cron Syntax
* Shell Scripting
* Automated Task Scheduling
* Log Management
* Error Logging
* Basic Error Monitoring

## 📂 Project Structure

```text
cron-job/
├── README.md
├── cron-syntax
├── crontab.log
├── error-check.sh
└── error.log
```

### Files

| File             | Purpose                                    |
| ---------------- | ------------------------------------------ |
| `cron-syntax`    | Common Cron scheduling syntax and examples |
| `crontab.log`    | Log output generated by scheduled jobs     |
| `error-check.sh` | Shell script for checking/logging errors   |
| `error.log`      | Stores detected error messages             |

## ⏱️ Cron Syntax

A Cron expression consists of five fields:

```text
* * * * *
│ │ │ │ │
│ │ │ │ └── Day of week
│ │ │ └──── Month
│ │ └───
```
